## ⭐ Featured projects

### [Context Graph](https://github.com/UofT-CSC490-W2026/Context-Graph)
Repository intelligence for LLM agents. It combines deterministic code indexing with claim-centric provenance retrieval, and exposes the result through an MCP server so agents can pull relevant context instead of reading whole repositories.
- Designed graph schemas and relationships to represent context across code, documentation, and tasks
- Built a synthetic repository and question set to measure multi-hop retrieval accuracy and token usage
- **Stack:** Python, MCP, Postgres, Neo4j, Docker, Terraform

### [Job Application Email Tracker](https://github.com/dkucz/JobApplicationEmails)
Scans job-application emails, extracts structured details with the Gemini API, and records them in Google Sheets. It runs automatically every day through GitHub Actions, triggered by a Google Apps Script.
- **Stack:** Python, Gemini API, Google APIs, GitHub Actions

### Soothsayer
A tarot-reading game built in Unity with a nine-person interdisciplinary team over 11 weeks. I designed gameplay and narrative systems, built a player statistics tracker, and used playtesting data to balance difficulty and scoring.
- **Stack:** Unity, C#
